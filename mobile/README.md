# Cliente Android LIFTLOG

Proyecto completo en Flutter 3.35.6, Dart 3.9.2. Consulta `../docs/ANDROID.md` para instalar, configurar ambientes y firmar. Consulta `../docs/USER_GUIDE.md` para utilizar la aplicación.

Pruebas ordinarias: `flutter analyze` y `flutter test`. La prueba `sync_live_test.dart` se omite salvo que se habilite explícitamente contra una API de ensayo. El harness `../scripts/test_native.py` crea esa API y la base desechable.

LIFTLOG - Instalador de pruebas para Windows

1. Extraiga todos los archivos del ZIP en una misma carpeta.
2. Conecte un solo telefono Android por USB y autorice la depuracion USB.
3. Abra CMD y ejecute instalar.cmd desde esa carpeta.

El instalador comprueba el SHA-256 de la APK antes de instalar. Si el archivo no coincide, se detiene. Usa adb install --no-streaming -r para copiar el paquete antes de instalarlo y conservar los datos de una instalacion compatible existente. No desinstala ni borra datos de aplicaciones.
